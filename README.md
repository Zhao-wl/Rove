# Rove

Rove 是一款面向 AI 协作的代码阅读与审阅器。它帮助你看清 AI 改了哪些文件、逐段审阅改动、做必要的小修，并把相关代码和问题打包交给外部 AI 继续处理。

## 计划中的核心能力

- **改动审阅**：用工作区检查点记录基线，跟踪外部文件变更，查看 diff 并逐段标记已审。检查点适用于 Git、SVN、Perforce 和未使用版本控制的目录。
- **代码阅读**：快速打开文件、全局搜索、查看大纲。首发聚焦 C#，计划支持符号搜索、定义跳转和引用查找。
- **局部编辑**：在审阅时修正少量代码，保存时保留原文件的编码和换行格式。
- **上下文打包**：将代码片段、差异和备注导出为 Markdown，便于交给外部 AI 追问。

## 项目状态

项目处于立项阶段，首发目标平台为 Windows 10/11 x64。技术路线采用 Rust 和原生 GPU 渲染。M0 将对比 GPUI 与自研渲染方案，验证大文件滚动、中文输入法、字体渲染、启动时间和内存占用。
