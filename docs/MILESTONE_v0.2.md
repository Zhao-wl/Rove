# 里程碑：v0.2 阅读体验

> 状态：**已确认范围**（2026-11-18）。依据：`MILESTONE_v0.1.md` §3.5、`issues/COVERAGE.md`、GitHub issue 现状（截至 `706c7fd`，v0.1.2 已发布）。

## 1. 目标

v0.1 之后剩下的 M4 条目分成两版推送：

- **v0.2（本文件）**：清理 v0.1 的跟进 bug 和偶发测试失败，补齐**阅读体验**相关的 P1（对应价值排序的第一位「高效阅读」）。
- **v0.3**：文档与工作区（JSON/YAML/XML、全局替换、文件操作、上下文篮子、跟随文件末尾）、个性化（扩展主题与文件图标、设置界面），以及 #75 M4 集成验收。

两版都通过自动更新推送；版本号仍然只改根 `Cargo.toml`（`AGENTS.md` §8.7）。

## 2. 起点（2026-11-18）

- 还没做的 M4 功能 issue 有 15 个，跟进 bug 和性能问题约 15 个。

## 4. 发布门槛

1. 3.1 和 3.2 的 issue 全部关闭，或者在 issue 里写明理由后正式移出本版。
2. #155 达到预算，或者按章程流程修订口径。
3. `perf/budgets.toml` 没有 `pending` 条目；`cargo xtask bench --check-budgets` 通过。
4. `cargo test --workspace -j 1` 全绿，并且阶段 A 处理过的偶发失败用例连续跑 10 次都通过。
5. 两个 Unity 测试项目上的阅读场景（打开、导航、新增的着色与缩略图）人工过一遍，结论写进验收记录。
