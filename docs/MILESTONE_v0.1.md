# 里程碑：v0.1 首发

> 状态：**已确认**（2026-11-13）。GitHub 里程碑「v0.1 首发」与本文件一一对应。
> 依据：`PLAN.md`、`PROJECT_CHARTER.md`（v0.3）、`docs/issues/README.md`、GitHub issue 现状（截至 `e393fd6`）。

## 1. 目标

这一版要把阅读、C# 导航、轻编辑三项主体功能做到可靠可用，能在干净的 Windows 10/11 x64 上安装使用，
**之后的功能通过自动更新推送**。

与原计划的差别：

- 原计划先完成 M1–M4，到 M5 才发布。现在改成 M3 结束后就发布 v0.1，M4 的大部分功能放到首发之后，随更新陆续推送。
- 原计划不做任何网络功能。现在新增**自动更新**，作为唯一的网络出口（`PROJECT_CHARTER.md` §2.1、`FEATURES.md` D11）。
- 仓库于 2026-11-13 公开，使用 MIT 许可，更新包从 GitHub Releases 获取。

## 5. 发布门槛（R77 逐条核对）

1. `COVERAGE.md` 中「v0.1」列为「是」的行全部完成，或者已经正式改判；
2. 两个 Unity 项目上的端到端场景通过；
3. 干净的 Windows 10 / 11 上安装 → 自动更新到 v0.1.1 → 卸载都通过，未保存的修改在更新后保留；
4. `rove.update.mode = "none"` 时整个会话零网络连接；`default` 时只有到 GitHub 的更新请求；
5. `perf/budgets.toml` 没有 `pending` 条目，`cargo xtask bench --check-budgets` 通过；
6. `cargo test --workspace` 全绿。

## 6. 已确认的决定（2026-11-13）

| 问题 | 决定 |
|---|---|
| 更新方式 | 自动更新，修订章程，作为唯一的网络出口（`PROJECT_CHARTER.md` §2.1） |
| 更新源 | GitHub Releases（`Zhao-wl/Rove`，仓库已公开） |
| 许可证 | MIT（`LICENSE`；workspace 的 `license` 字段同步改为 `MIT`；`vendor/gpui` 仍是 Apache-2.0） |
| 使用者 | 目前主要是维护者本人；不提前做英文界面、英文 README 和 issue 模板 |
| 代码签名 | 不签名，接受 SmartScreen 提示；安全性靠 ed25519 签名的更新清单加 SHA256 |
| `rove.update.mode` 默认值 | `default`（启动后检查、后台下载、提示重启）；键名加 `rove.` 前缀，避免与 VS Code 的 `update.mode` 冲突 |
| 更新通道 | 只有一个稳定通道 |
| 截止日期 | 不设；按依赖推进 |
| 安装器 | Inno Setup（用户级安装、静默升级） |
| 便携版 | 不自动更新，只提示有新版本并打开 Release 页面 |
| 提前条目的范围 | R51、R52、R54、R57、R59 按原 issue 的完整范围做 |
| WebView2 | 不捆绑；没有运行时时 Markdown 预览显示降级提示 |
