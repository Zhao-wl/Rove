# Rove 立项文档

> 版本：v0.2（草案） · 日期：2026-11-09
> 变更：首版移除 AI 改动感知；明确核心是“高效阅读”（性能 + 跳转/引用响应）；语言智能另立设计文档。

## 1. 定位

**Rove 是一个高性能、轻量的代码阅读编辑器。**

价值排序：

1. **高效阅读**：打开快、滚动顺、跳转与引用响应即时且准确
2. **编辑**：可靠的局部编辑能力
3. **辅助**：把选中内容打包交给外部 AI（轻量功能）

## 2. 明确不做（Non-Goals）

| 不做 | 原因 |
|---|---|
| 内置 AI（对话、补全、Agent） | Rove 不是 AI 工具本身 |
| 插件系统 | 插件是 VS Code 变重的根源 |
| 终端 / 命令行面板 | 交给外部工具 |
| 编译、构建、调试 | 同上 |
| 版本控制操作 | 超出阅读器范围 |
| Remote / SSH / 协同编辑 / Notebook | 超出阅读器范围 |
| 用网页内核构建界面（Electron、整体 WebView） | 违背高性能渲染路线。**唯一例外**：Markdown 预览使用系统自带的 WebView2，按需创建（D5，2026-11-09） |
| AI 改动感知 | 首版不做，后续视需求再评估 |

## 3. 首发范围

- **平台**：Windows 10/11 x64 首发；后续扩展 macOS；暂不支持 Linux。
- **编程语言**：C#，提供完整的语言智能，详见 [LANGUAGE_INTELLIGENCE.md](LANGUAGE_INTELLIGENCE.md)。
- **文本类型**：JSON、YAML、XML、Markdown。
- **通用**：纯文本、超大文件、编码识别（UTF-8/UTF-16/GBK）、CRLF/LF。

## 4. 功能设计

### 4.1 高效阅读（核心）

- 工作区文件树、多标签、分屏、快速打开（模糊匹配）
- 全局文本搜索（ripgrep 内核）
- 文件大纲、面包屑、符号搜索（工作区级）
- C# 定义跳转、查找引用、查找实现、悬停签名、导航前进/后退（详见语言智能文档）
- 超大文件：内存映射 + 按需分行 + 虚拟滚动；超过阈值时自动降级（关闭语法分析）
- 文件树只做性能层面的排除：默认跳过 `Library/`、`Temp/`、`obj/`、`.git/` 等大目录，支持用户配置，不依赖 `.gitignore` 语义

### 4.2 编辑

- rope 文本缓冲（`ropey`），撤销/重做，保存时保持原编码与换行符
- 输入、删除、复制粘贴、行操作、多光标、缩进、注释切换
- 查找替换（当前文件）
- 中文输入法（IME）完整支持
- 外部修改时自动重载（无本地未保存修改时）

### 4.3 文档类型渲染

| 类型 | 能力 |
|---|---|
| JSON | 高亮、折叠、结构树、格式化/压缩、校验报错定位、JSON 路径显示 |
| YAML | 高亮、折叠、结构树、校验 |
| XML | 高亮、折叠、标签配对、结构树、校验 |
| Markdown | 高亮编辑 + 完整预览（WebView2，含内嵌 HTML、Mermaid、数学公式，D5）；默认以预览打开（D6）；滚动同步 |

### 4.4 上下文打包（轻量辅助）

选中代码区间（可多段）→ 导出为结构化 Markdown（路径、行号、所属符号、代码、备注）到剪贴板。不发起任何网络请求。

## 5. 技术路线

- **全 Rust** 主程序，核心层与 UI 层解耦
- **GPU 原生渲染**，不用 WebView 构建界面（唯一例外：Markdown 预览，D5）；**UI 框架：GPUI 0.2.2**（M0 定案，附 5 项约束，见 [M0_UI_SPIKE_REPORT.md](M0_UI_SPIKE_REPORT.md) §7）
- **性能优先**：UI 方案和实现取舍以性能为第一标准，代码视图自己实现 Element，并把整形移出绘制关键路径
- **核心层对 UI 零依赖**：只有 `rove-ui` / `rove-app` 可以依赖 `gpui`
- C# 精确语义使用独立的 Roslyn 索引进程（.NET），详见语言智能文档
- 所有耗时操作都放在后台线程，UI 线程只做布局和绘制

### crate 划分（Cargo workspace）

```
crates/
  rove-buffer     文本缓冲、编码识别、大文件 mmap
  rove-syntax     tree-sitter 集成、高亮、折叠、大纲
  rove-workspace  工作区扫描、文件监听、全局搜索
  rove-lang-cs    C# 语言智能：快速索引 + 语义索引读取 + 查询路由
  rove-docview    JSON/YAML/XML 结构树（Markdown 预览由 WebView2 渲染，不在此 crate）
  rove-ui         UI 组件
  rove-app        程序入口、配置、窗口管理
tools/
  rove-indexer-cs .NET/Roslyn 语义索引进程
```

## 6. 性能指标（纳入 CI 基准测试）

| 指标 | 目标 |
|---|---|
| 冷启动到可交互 | < 400 ms（2026-11-09 修订）。“可交互”指首帧已呈现、且第一个输入事件能在一帧内得到响应；M0 实测 GPUI 到首帧的中位数为 396 ms，首帧时间另行记录 |
| 空窗口常驻内存 | < 60 MB |
| 打开 1 GB 文本文件 | < 1 s，滚动稳定 120 fps |
| 按键到上屏延迟 | < 8 ms |
| 连续滚动时每帧 CPU（整形缓存命中） | < 1 ms（M0 实测 GPUI 原型 823 µs；缓存全未命中时帧间隔 p99 ≤ 1.5 倍刷新间隔） |
| 定义跳转响应（语义索引就绪时） | < 16 ms |
| 查找引用响应（语义索引就绪时） | < 50 ms |
| 导航界面端到端（按下 `F12` 到目标位置绘制完成，目标文件已打开） | < 50 ms |

> 前两项是索引查询本身的耗时；第三项是界面侧的端到端耗时，两者在 `perf/budgets.toml` 中分开记录。
| 发布包体积（不含 C# 索引组件） | < 30 MB |

参考设备：主流办公机（8 核 / 16 GB / SSD / 集显）。

## 7. Windows 专项风险

- 中文 IME：候选框跟随光标、组合态渲染（M0 必测）
- DirectWrite 字体效果、中文/emoji 字体回退、高 DPI 与多显示器不同缩放比
- 编码：GBK、带 BOM 的 UTF-8、UTF-16，保存时保持原编码
- 长路径（> 260 字符）、大小写不敏感路径
