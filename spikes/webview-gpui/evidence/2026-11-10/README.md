# Versioned review reruns

Three fresh-profile --auto runs of one release executable. Each log begins with
schema 2 build identity; .run.json files contain executable SHA-256 and start time.
verify_run.py checks current source fingerprint as well as runtime probes.
summary.json separates all replies and each kind; >16ms means strictly greater
than 16ms, percentiles use nearest rank. This is continuous-frame instrumentation,
not idle memory or OS-cold-start evidence. No physical keys or valid screenshots
were collected. Do not use these passes to remove the visual/focus gate.
